# Domain Name

## Main info

A **domain name** is a human-readable address used to access websites and other internet resources. Instead of remembering long IP addresses, domain names provide a simple and easy way for users to access websites by typing a recognizable string of text.

### Purpose of Domain Names:
The primary goal of a domain name is to simplify internet navigation by providing a readable and memorable address that users can type instead of numerical IP addresses, making the internet more user-friendly.

## Additional Info
### Key Points:

1. **Structure**:
   A domain name consists of multiple parts, typically separated by dots. It usually follows this structure:
   - **Top-Level Domain (TLD)**: The last part of the domain name, such as `.com`, `.org`, `.net`, or country-specific domains like `.uk` (United Kingdom) or `.jp` (Japan).
   - **Second-Level Domain (SLD)**: The part of the domain that comes immediately before the TLD. For example, in `example.com`, "example" is the second-level domain.
   - **Subdomain** (Optional): An additional part of the domain that can be added before the second-level domain, such as `blog.example.com`, where "blog" is the subdomain.

   Example:
   - `www.example.com`
     - `www`: Subdomain (optional, not always present)
     - `example`: Second-level domain
     - `.com`: Top-level domain (TLD)

2. **Domain Name System (DNS)**:
   Domain names are part of the **Domain Name System (DNS)**, which acts like a phonebook for the internet. When a user types a domain name into their browser, the DNS translates the domain name into the corresponding **IP address** of the web server hosting that site, allowing the browser to load the website.

   For example:
   - A user types `www.example.com`.
   - DNS resolves the domain name to an IP address like `192.0.2.1`.
   - The browser connects to the server with that IP address to load the website.

3. **Types of Domain Names**:
   - **Generic Top-Level Domains (gTLDs)**: Common TLDs such as `.com`, `.org`, and `.net`.
   - **Country Code Top-Level Domains (ccTLDs)**: TLDs specific to countries, such as `.us` for the United States or `.de` for Germany.
   - **Sponsored Top-Level Domains (sTLDs)**: TLDs for specific organizations or purposes, such as `.gov` for U.S. government entities or `.edu` for educational institutions.

4. **Domain Registration**:
   Domain names must be registered through a **domain registrar** (e.g., GoDaddy, Namecheap, Google Domains). Registrants usually pay an annual fee for the right to use the domain name. Once registered, the domain can be pointed to a hosting provider's server where the actual website content resides.

### Examples of Domain Names:
- **Google.com**: The domain name for Google’s search engine.
- **Wikipedia.org**: The domain name for the online encyclopedia Wikipedia.
- **Amazon.co.uk**: A domain name using a country-specific TLD for Amazon’s UK website.
