# HTTPS

- HTTPS A secure version of HTTP. It adds encryption so that only the website and the client can read the data sent over the Internet. 

- The website encrypt the message with a key that can only be decoded with the user key. 
- HTTP uses port 80 
- HTTPS uses port 443 

- HTTPS needs certificate, how? 
	- Free: Certbot (LetsEncrypt) 
	- Paid: Why?
		- Some websites (like banks' websites) needs to get certificates from specific organizations
