# Turn Computer to Server

You can use a **Web Server** (Apache, Nginx, IIS) 
- Listens for Requests 
- Serves Files and Content 
- Reroute requests to the correct backend code base
- Sends Responses Logs and Monitoring 
- Security: Limit unauthorized
- HTTP & HTTPS Manages Connections (some tweaks can be very critical)
